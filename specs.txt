# Live Weather Data Application

A responsive static website for observations from MeteoSwiss stations.
Serve the repository root over HTTP and open /dashboard/ or /maps/.

## Features

- Search the bundled Swiss station index, with a built-in fallback.
- Explore all station locations on a searchable map, with a shared station selection.
- Show current measurements and one-hour trends when a baseline exists.
- Explore temperature, wind, pressure, dewpoint, humidity, precipitation,
  sunshine, and radiation using native SVG charts.
- Link selected chart points to the recent readings table.
- Export the displayed observations as CSV, including timestamps and source.
- Customize metric visibility and order; the first visible metric is primary.
- Save and reorder favorite stations using drag-and-drop or keyboard controls.
- Persist station, range, theme, favorites, metric order, and visibility locally.
- Support mobile layouts, light/dark themes, and reduced-motion preferences.

## Architecture

- dashboard/app.js: browser startup, controls, and current-condition rendering.
- dashboard/model.js: application state and asynchronous loading lifecycle.
- weather.js: parsing, normalization, caching, merging, and calculations (shared).
- dashboard/chart.js: SVG rendering, chart interaction, table, and CSV download.
- config.js: fallback stations, metrics, parameter aliases, time ranges (shared).
- storage.js: validated preference reads and best-effort writes (shared).
- site.js: shared site theme behavior used by the dashboard and map.
- format.js: shared display and CSV formatting.
- dashboard/style.css: theme tokens, component styles, responsive rules.
- maps/: searchable station map, reusing the shared station, storage, theme, and text utilities.

## Data sources

- Station index: assets/coord_station_meteosuisse.json (158 stations).
- API base: https://data.geo.admin.ch/ch.meteoschweiz.ogd-smn
- Map library: Leaflet 1.9.4 from unpkg; base tiles © OpenStreetMap contributors.
- Current: {base}/{code}/ogd-smn_{code}_t_now.csv
- Recent: {base}/{code}/ogd-smn_{code}_t_recent.csv
- Endpoint station codes are lowercase.

## Data handling

- Non-empty successful feeds have a 10-minute in-memory cache.
- Manual refresh clears the selected station's cache.
- Poll the current feed every 30 seconds to signal newer observations.
- Ignore responses superseded by another station/data request.
- Merge feeds by timestamp, preserving complementary measurements.
- Report live, partial, or unavailable data; never synthesize observations.
- Use the latest merged observation for current conditions, including when
  only the recent feed is available.
- Interpret Swiss-format and compact observation timestamps as UTC.

## History ranges

- 3h, 6h, 12h, 24h: individual observations within the rolling range.
- 7d: averages of groups of three observations within each hour.
- 30d: averages in two-hour blocks.
- Wind direction is averaged circularly.
- All selected ranges are limited by current/recent feed coverage.
- Chart, table, and export share the same displayed dataset.
- Measurements with shared units share a chart scale; direction uses 0–360°.

## Development

- No build step. The dashboard has no runtime JavaScript dependencies; maps loads Leaflet from a CDN and OSM tiles.
- External web fonts: DM Sans, DM Mono, Manrope (with system fallbacks).
- Node.js 20+ for development checks: npm ci; npm test; npm run format:check.
- Full setup, module guide, behavior, and controls: dashboard/README.md.
